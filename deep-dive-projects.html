Key Code — eKYC Kafka Consumer
@Service public class EkycKafkaConsumer { @Autowired private UidaiApiClient uidaiClient; @Autowired private RedisTemplate<String, String> redis; @Autowired private KafkaTemplate<String, Object> kafkaTemplate; @KafkaListener(topics = "kyc.initiation.requested", groupId = "ekyc-group") public void handleKycInitiation(KycInitiationEvent event) { // 1. Generate OTP via UIDAI mock API String otp = uidaiClient.generateOtp(event.getAadhaarNumber()); // 2. Store OTP in Redis with 10-min TTL redis.opsForValue().set( "otp:" + event.getCitizenId(), otp, 10, TimeUnit.MINUTES ); // 3. Publish OTP-sent event for notification kafkaTemplate.send("kyc.otp.sent", new KycOtpSentEvent(event.getCitizenId(), event.getMobile())); } @KafkaListener(topics = "kyc.otp.verify.requested", groupId = "ekyc-group") public void handleOtpVerification(KycOtpVerifyEvent event) { String storedOtp = redis.opsForValue().get("otp:" + event.getCitizenId()); if (storedOtp != null && storedOtp.equals(event.getSubmittedOtp())) { // Fetch demographic data from UIDAI AadhaarDemographic demo = uidaiClient.fetchDemographic(event.getAadhaarNumber()); kafkaTemplate.send("kyc.verification.completed", new KycCompletedEvent(event.getCitizenId(), "VERIFIED", demo)); } else { kafkaTemplate.send("kyc.verification.completed", new KycCompletedEvent(event.getCitizenId(), "FAILED", null)); } } }

Core Concept — Schema-Per-Tenant Isolation
How it works: Every tenant gets their own PostgreSQL schema (tenant_acme, tenant_xyz). A TenantContext ThreadLocal holds the tenant ID extracted from the JWT. A custom TenantAwareDataSource routes every DB connection to the right schema automatically. Liquibase runs migrations per schema on tenant provisioning.
// 1. TenantContext — ThreadLocal holder public class TenantContext { private static final ThreadLocal<String> TENANT = new ThreadLocal<>(); public static void setTenantId(String tenantId) { TENANT.set(tenantId); } public static String getTenantId() { return TENANT.get(); } public static void clear() { TENANT.remove(); } } // 2. Gateway Filter — extract tenant from JWT claim @Component public class TenantResolutionFilter implements GlobalFilter { @Override public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) { String tenantId = exchange.getRequest().getHeaders() .getFirst("X-Tenant-ID"); // set by Keycloak JWT claim exchange.getRequest().mutate() .header("X-Tenant-ID", tenantId).build(); return chain.filter(exchange); } } // 3. AbstractRoutingDataSource — routes to correct schema @Component public class TenantAwareDataSource extends AbstractRoutingDataSource { @Override protected Object determineCurrentLookupKey() { return TenantContext.getTenantId(); // returns "tenant_acme" } } // 4. Request Interceptor — set tenant in ThreadLocal per request @Component public class TenantInterceptor implements HandlerInterceptor { @Override public boolean preHandle(HttpServletRequest req, ...) { String tenant = req.getHeader("X-Tenant-ID"); TenantContext.setTenantId(tenant); return true; } @Override public void afterCompletion(...) { TenantContext.clear(); } }

Key Code — Onboarding Saga + Tenant Schema Provisioning
// Onboarding Saga — tracks state across services via Kafka events @Service public class OnboardingSagaOrchestrator { @Autowired private KafkaTemplate<String, Object> kafka; @Autowired private OnboardingStateRepository stateRepo; public void startOnboarding(TenantRegistrationRequest req) { OnboardingState state = stateRepo.save(new OnboardingState( req.getTenantId(), "SCHEMA_PROVISIONING" )); kafka.send("tenant.onboarding.initiated", new TenantOnboardingEvent(req.getTenantId(), req.getPlan())); } @KafkaListener(topics = "tenant.provisioned") public void onTenantProvisioned(TenantProvisionedEvent event) { stateRepo.updateStatus(event.getTenantId(), "IAM_SETUP"); // Next step: IAM service will create Keycloak realm } @KafkaListener(topics = "iam.realm.created") public void onRealmCreated(IamRealmCreatedEvent event) { stateRepo.updateStatus(event.getTenantId(), "COMPLETED"); kafka.send("notification.events", new WelcomeEmailEvent(event.getTenantId(), event.getAdminEmail())); } } // Tenant Schema Provisioner — creates PostgreSQL schema + runs Liquibase @Service public class TenantSchemaProvisioner { @Autowired private DataSource dataSource; @KafkaListener(topics = "tenant.onboarding.initiated") public void provisionSchema(TenantOnboardingEvent event) { String schema = "tenant_" + event.getTenantId().replace("-", "_"); try (Connection conn = dataSource.getConnection()) { // 1. Create schema conn.createStatement().execute( "CREATE SCHEMA IF NOT EXISTS " + schema ); // 2. Run Liquibase migrations for this schema Database db = DatabaseFactory.getInstance() .findCorrectDatabaseImplementation(new JdbcConnection(conn)); db.setDefaultSchemaName(schema); Liquibase liquibase = new Liquibase( "db/tenant-changelog.xml", new ClassLoaderResourceAccessor(), db ); liquibase.update(""); } // Publish success event kafka.send("tenant.provisioned", new TenantProvisionedEvent(event.getTenantId(), schema)); } }
Key Code — Stripe Webhook Handler
@RestController @RequestMapping("/api/billing/webhooks") public class StripeWebhookController { @Value("${stripe.webhook.secret}") private String webhookSecret; @Autowired private KafkaTemplate<String, Object> kafka; @PostMapping("/stripe") public ResponseEntity<String> handleStripeWebhook( @RequestBody String payload, @RequestHeader("Stripe-Signature") String sigHeader) { Event event; try { // Validate Stripe signature — prevents fake webhooks event = Webhook.constructEvent(payload, sigHeader, webhookSecret); } catch (SignatureVerificationException e) { return ResponseEntity.badRequest().body("Invalid signature"); } switch (event.getType()) { case "customer.subscription.created": kafka.send("subscription.activated", buildActivatedEvent(event)); break; case "customer.subscription.deleted": kafka.send("subscription.cancelled", buildCancelledEvent(event)); break; case "invoice.payment_failed": kafka.send("invoice.payment.failed", buildPaymentFailedEvent(event)); break; } return ResponseEntity.ok("OK"); } }

📄 Resume Bullet Points — Multi-Tenant SaaS Platform
Architected multi-tenant SaaS backend using PostgreSQL schema-per-tenant isolation with Hibernate multi-tenancy, AbstractRoutingDataSource, and automated per-tenant Liquibase schema migration on provisioning.
Implemented Saga pattern for tenant onboarding orchestration across 3 services (tenant-service → iam-service → notification-service) via Kafka events with compensating transaction rollback on failure.
